# ☕ Coffee Sales Dashboard (Excel Project)

An interactive Excel dashboard built to analyze coffee sales data and provide key business insights.

## 📊 Project Overview

This project visualizes coffee sales across products, regions, and time periods. It includes dynamic charts and KPIs to track performance and support data-driven decisions.

### Key Features:
- Product-wise and region-wise sales breakdown
- Monthly sales trends
- Dynamic filtering using slicers
- KPIs for revenue, profit, and quantity sold

## 🔧 Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers and Timeline Filters
- Data Cleaning & Formatting

## 🧠 Insights Provided

- Which coffee products are top performers?
- How do sales vary across regions and months?
- Which combinations of product and region drive the most revenue?

## 📌 How to Use

1. Download the Excel file above.
2. Open in Microsoft Excel (2016 or later recommended).
3. Use slicers to filter data by region, product, or month.
4. Explore KPIs and visuals for insights.
